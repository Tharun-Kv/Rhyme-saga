# **App Name**: Rhyme Sage

## Core Features:

- Poem Generation: Generate a poem based on a user-provided topic and style, using AI.
- Suggestive Tool: Suggest appropriate words and phrases that might work well within the user's poem, operating as a tool for writing.
- Poem Display: Display the generated poem in a formatted text area.
- Edit Poem: Allow users to edit and refine the generated poem.
- Export Poem: Allow users to export the generated poem as a .txt file.

## Style Guidelines:

- Primary color: A muted blue (#7395AE) evokes a thoughtful and creative atmosphere.
- Background color: Very light desaturated blue (#D1DADE) to keep the focus on the generated content.
- Accent color: A slightly brighter, analogous blue (#6D86A3) to highlight key interactive elements without distracting from the poem's display.
- Font for headings and body: 'Literata', a transitional serif that is comfortable to read, giving the app a literary feel.
- A clean and simple layout to keep the focus on the poem.
- Subtle fade-in animations on text to create a smooth experience.
